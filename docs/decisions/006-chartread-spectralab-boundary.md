# 006 - Tidigare förslag om gräns mot SpectraLab

> Historical planning/research/decision record. The dated findings are preserved; use [the v1.0.0 documentation index](https://github.com/chto0703009/InkProf-public/blob/main/docs/README.md) for current usage and status.

Datum: 2026-09-26. **Ersatt av [beslut 007: självständigt InkProf](007-independent-inkprof.md).**

Det tidigare förslaget var att låta SpectraLab hantera punktmätning och omläsning genom en adapter. Projektägaren valde i stället en egen implementation i InkProf, för att hålla projekten självständiga. Ingen sådan SpectraLab-adapter ska implementeras som körberoende.

Erfarenheter från SpectraLabs sessionshantering kan användas som underlag. Aktuellt ansvar, revisionskrav och verifieringsstatus finns i beslut 007 och [mätanvisningen](../usage/chart-measurement.md).
