# Abbreviations in InkProf

> InkProf 1.0.0-rc.2, version marking updated 2026-10-08. See the [current app workflow](workflow-v1.0.md) for the complete 19-step process. Dated experiments and legacy examples below retain their original scope.

Abbreviations should be explained at first use in any self-contained description or report. This glossary is a supplement.

| Term | Meaning and function |
|---|---|
| bvdm | Bundesverband Druck und Medien, Germany's industry association for print and media. Publisher of MediaStandard Print, an industry publication summarizing standard requirements. |
| ISO | International Organization for Standardization. A reference to ISO should state the standard number and the relevant edition. |
| ICC | International Color Consortium. The organization behind the profile format used to describe a device's colour reproduction. |
| CIE | Commission Internationale de l'Éclairage, the International Commission on Illumination. |
| ΔE00 / CIEDE2000 | A computed measure of colour difference. A lower value means a smaller difference by this measure; the acceptable limit depends on use and test conditions. |
| D50 / D65 | Standardized daylight distributions with correlated colour temperatures of about 5,000 and 6,500 kelvin. The temperature alone does not define the spectrum of the light. |
| BPC | Black Point Compensation. Adjusts dark tones during colour conversion. |
| FWA / OBA | Fluorescent Whitening Agent / Optical Brightening Agent in paper. |
| RGB / sRGB | Red, Green, Blue. sRGB is a standardized RGB colour space; a printer's control values are not automatically sRGB. |
| Lab / CIELAB | The CIE colour space with lightness L* and the colour axes a* and b*. |
| A2B / B2A | The ICC profile's conversion from device values to the profile connection space, and the opposite direction. |
| PCS | Profile Connection Space, the common connection colour space of ICC profiles. |
| P95 | 95th percentile: 95 percent of the values are at or below this value, by the percentile computation used. |
| TIFF16 | Tagged Image File Format with 16 bits per colour channel. |
| JSON | JavaScript Object Notation, a text format for structured project and measurement data. |

Source for the organization's name and role: [Bundesverband Druck und Medien – about the organization](https://www.bvdm-online.de/bvdm/ueber-uns/).
