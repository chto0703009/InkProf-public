# Förkortningar i InkProf

> v1.0.0 preparation (1.0.0-rc.1), reviewed 2026-10-03. See the [current app workflow](workflow-v1.0.md) for the complete 19-step process. Dated experiments and legacy examples below retain their original scope.

Förkortningar ska förklaras vid första användningen i en fristående beskrivning eller rapport. Denna ordlista är ett komplement.

| Begrepp | Betydelse och funktion |
|---|---|
| bvdm | Bundesverband Druck und Medien, Tysklands branschorganisation för tryck och medier. Utgivare av MediaStandard Print, en branschpublikation som sammanfattar standardkrav. |
| ISO | International Organization for Standardization, Internationella standardiseringsorganisationen. En hänvisning till ISO ska ange standardnummer och relevant utgåva. |
| ICC | International Color Consortium. Organisationen bakom profilformatet som används för att beskriva en enhets färgåtergivning. |
| CIE | Commission Internationale de l’Éclairage, Internationella belysningskommissionen. |
| ΔE00 / CIEDE2000 | Ett beräknat mått på färgskillnad. Lägre värde betyder mindre skillnad enligt detta mått; godtagbar gräns beror på användning och provningsvillkor. |
| D50 / D65 | Standardiserade dagsljusfördelningar med ungefär 5 000 respektive 6 500 kelvin korrelerad färgtemperatur. Temperaturtalet ensamt definierar inte ljusets spektrum. |
| BPC | Black Point Compensation, svartpunktskompensation. Anpassar mörka toner vid färgomvandling. |
| FWA / OBA | Fluorescent Whitening Agent / Optical Brightening Agent, fluorescerande eller optiskt vitmedel i papper. |
| RGB / sRGB | Red, Green, Blue: röd, grön och blå. sRGB är en standardiserad RGB-färgrymd; skrivarens styrvärden är inte automatiskt sRGB. |
| Lab / CIELAB | CIE:s färgrymd med ljushet L* och färgaxlarna a* och b*. |
| A2B / B2A | ICC-profilens omvandling från enhetsvärden till profilens anslutningsfärgrymd, respektive motsatt riktning. |
| PCS | Profile Connection Space, ICC-profilernas gemensamma anslutningsfärgrymd. |
| P95 | 95:e percentilen: 95 procent av värdena ligger på eller under detta värde, enligt använd percentilberäkning. |
| TIFF16 | Tagged Image File Format med 16 bitar per färgkanal. |
| JSON | JavaScript Object Notation, textformat för strukturerade projekt- och mätdata. |

Källa för organisationens namn och roll: [Bundesverband Druck und Medien – om organisationen](https://www.bvdm-online.de/bvdm/ueber-uns/).
