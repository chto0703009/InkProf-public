# InkProf v1.0.1 — stable patch release

Released 2026-10-11 with publication approved by Christer Törnkvist. Source version **1.0.1**, tag **v1.0.1**. [Download the release](https://github.com/chto0703009/InkProf-public/releases/tag/v1.0.1). The existing v1.0.0 tag and assets are preserved.

## Changes since v1.0.0

- Test actual Python package imports, including SciPy spatial and sparse modules, before analysis. Show the selected runtime and repair instructions when imports fail. Pin SciPy 1.16.3 after the reported Apple M4/Python 3.13 import failure with 1.15.3. Instrument measurement can still use its standard-library-only bridge.
- Place the three separate RGB spot controls above the chart at the upper right, alongside the heading. Restore 16 mm of chart height for measurement rows. Existing printed targets retain their original placement and remain measurable.
- Show the active page and R/G/B colour prominently, and name that same page and colour on the measurement button. Remeasure a selected completed control or restart the whole sequence in the same window. Preserve earlier readings separately; an unfinished retry cannot reuse a prior pass or override.
- Explain that reference-target repeats are extra copies, not the total patch count. Validate the selected reference set's repeat limit before creating C2.
- Keep elapsed-time feedback visible over the correct foreground window during step 8 checks, TIFF16 preview creation and C2 finalization.
- Rebuild the Swedish and English handbooks and presentations, and the English MATLAB workflow guide, with version 1.0.1 and current instructions.

## Assets

A ZIP from the reviewed public source commit, five documentation PDFs, VALIDATION.txt and SHA256SUMS. No private project data, measured profiles, third-party reference targets, virtual environment or external runtime binaries are included. MATLAB, Python and ArgyllCMS are installed separately.

## Validation scope

See VALIDATION.txt for exact results. Automated tests use synthetic instrument responses; no new physical instrument, print, paper or platform qualification is claimed. The reported M4 import test verifies the dependency imports, not the complete profiling workflow on that machine. Windows/Linux instrument compatibility and ISSUE-001 remain outside this patch release's qualification. Certificates document measurements and decisions; they are not accredited certification.
