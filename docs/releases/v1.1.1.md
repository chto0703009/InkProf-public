# InkProf v1.1.1 - measurement workflow release

Release date: 2026-10-14. Source version 1.1.1; public tag v1.1.1. Maintainer-authorised release. [Download](https://github.com/chto0703009/InkProf-public/releases/tag/v1.1.1).

## Changes since v1.1.0

- Save completed physical rows as immutable measurement checkpoints, then resume the same target with saved settings and guided page/row/direction instructions.
- A save requested during a scan waits for a row prompt and excludes that row. A half-completed forward/reverse pair is removed from the resume snapshot and reread in both directions.
- Require confirmation of the same physical printed sheets. A reprint or replaced page needs a new session and fresh RGB checks; a file checksum cannot identify paper sheets.
- Reuse approved RGB controls for the same print, with target/control identity validation. Cancelled or failed RGB checks allow a corrected restart.
- Continue to the following scan after a successful manually selected reread.
- Increase RGB control squares by 0.5 mm on each edge and keep labels/measurement rectangles aligned. Existing TIFF files are unchanged.
- Create a new C2 target directly when no saved target exists for the current ICC.
- Update handbooks, presentations, MATLAB guide and usage documentation. Explain later OBA/FWA selection using retained native spectra, without code changes.
- Include clearly labelled future-development proposals; profile tweaking is not implemented by this release.

## Updating an existing installation

Save any active measurement checkpoint, close InkProf and restart MATLAB after replacing source files so updated classes are loaded. Reopen the existing project; do not regenerate an already printed target just to obtain the larger RGB squares. Existing TIFFs keep their original geometry.

## Qualification and limitations

Automated tests exercise synthetic instruments, checkpoint integrity, partial-row exclusion and resumption instructions. They do not validate physical printer quality or the new save/resume workflow with a real instrument. Real-instrument resume qualification remains necessary and is recorded in VALIDATION.txt. Windows/Linux and other instruments retain their existing qualification limits. ISSUE-001 (inverse sensitivity to measurement noise) remains open.

Existing saved profiles, measurement revisions and TIFF targets are not rewritten. Checkpoints are not complete accepted measurements. Measurements since the last successful checkpoint can be lost after an unexpected interruption. Profiling and colour validation require the documented independent checks.

This is source-only GPL-3.0-or-later software, without warranty. MATLAB, Python, ArgyllCMS and test dependencies are installed separately. Private projects, measurements, ICC profiles and excluded third-party fixtures are not distributed. Historical releases and their assets remain unchanged.

## Reproduction

- `python -m unittest discover -s tests -p 'test_*.py'`
- MATLAB: `addpath('src'); r=runtests('tests'); disp(table(r)); assertSuccess(r)`
- `node tests/test_gamut_view.js`
- `python tools/check_release.py`
- `python tools/check_license_inventory.py`

Use requirements-test.txt for the Python test environment. Configure that interpreter with setupInkProf(PythonExecutable="/absolute/path/to/python", CheckPython=true) before MATLAB tests, and set INKPROF_TEST_PYTHON to the same interpreter. Local runtime settings are excluded from the release. PDF sources are included in docs/usage; six documentation PDFs are delivered, including the separate future-development discussion.
