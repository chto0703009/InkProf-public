# InkProf v1.2.6 - Preserve original projects during print delivery

Released 2026-10-24. Source-only patch release.

- Reserve new print-copy folders atomically; never reuse or replace an existing destination.
- Reject copying an entire project as a target package and reject package-copy destinations inside the original project.
- Check original manifest and TIFF hashes after copying, before recording success. Validate C2 ICC identity before starting delivery.
- Mark print folders with PRINT_COPY_ONLY.txt, including incomplete copies. Explain print-copy selection with its original project path; show both original and copy paths after successful export.
- Guard explicit project renames: same parent only, no existing destination or Trash path, identity verification and rollback by rename without deleting either location.
- Document that original measurements must never be overwritten, deleted or sent to Trash. Corrections and remeasurements remain separate revisions.

An investigation of a recovered project did not establish the actor or operation that moved it to Trash. No Trash operation was found in the print-copy chain or project history; this release does not claim to have proven the historical cause. These safeguards apply to InkProf operations and cannot prevent external Finder/operating-system actions.

Validation: 17 focused MATLAB tests cover failed/cancelled copy preservation, immutable source hashes, collisions, Unicode paths, metadata edits and rename locks, and exact C2 ICC delivery. Source/version/notice checks passed. No new full-suite or physical printing/instrument qualification is claimed. The eight PDF guides retain the reviewed v1.2.4 edition; v1.2.6 preservation rules are in current Markdown.

Restart MATLAB to load the new helpers and classes. MATLAB, Python and ArgyllCMS are separate dependencies. Private project data and the local incident audit are excluded from release assets.
