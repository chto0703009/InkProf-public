# InkProf v1.2.0 — measurement delivery and bilingual certificates

Released 2026-10-16. This feature release supersedes the unpublished v1.1.2
preparation. No v1.1.2 tag or public release was published.

## Changes since v1.1.1

- Optional CGATS measurement export for i1Profiler via a checkbox in rows 14/19, with no additional confirmation dialog. Deliver the selected original native M0 measurement as TXT plus provenance JSON. See [instructions and test scope](../usage/i1profiler-cgats-test.md).

- Create Swedish PDF certificates alongside English PDF/HTML. The supplement remains English.
- Deliver both certificate PDFs and `measurement-appendix.pdf` directly in the selected delivery folder, also when re-exporting older packages.
- Optional offline 3D viewer of all fitting measurements for the current ICC and its current verification points, with separate groups, point details and L* filtering. Latest selects current verification in step 14; step 19 uses fitting data and does not borrow an old verification.
- Show up to 100 largest unrounded ΔE00 deviations strictly above 1 in ascending order. Desired and measured colours form pairs; numeric labels are centred. All measured patches, including repeats and paper white, remain in the supplement with colour previews, Lab, SHA-256 checksums and history.
- Improve English/Swedish terminology, legends, local timestamps, title placement, numeric alignment and the L* 40–60 verification plot.
- Document and test the integrity boundary: create revised reports through a new workflow export; never overwrite registered export files directly.
- Update both handbooks, both presentations, the MATLAB workflow guide and the clearly labelled future-development overview.

## Upgrade and existing projects

Close InkProf and restart MATLAB after installing the source update, then reopen
the existing project. No new measurement or profile build is required solely to
obtain revised certificates. Run step 14 for the approved current verification or
step 19 for an explicitly numerical-only certificate. Open the newly created
delivery folder; older bundles are not rewritten. Previously saved ICC profiles,
raw measurements and printed TIFF16 targets are retained.

## Validation and delivery

See VALIDATION.txt for exact test scope and results. The release assets contain
the sanitised source ZIP, six documentation PDFs, these notes, validation and
SHA256SUMS. Repository and Downloads documentation copies are byte-identical.
The separate public repository contains reviewed source changes, not private
project data or the private development history.

## Scope and limitations

Source-only GPL-3.0-or-later software, without warranty. Install MATLAB, Python
and ArgyllCMS separately. No private projects, measurement reports, ICC profiles,
local settings or restricted third-party test fixtures are distributed.
Numerical tests and report layout checks do not qualify physical print accuracy.
Real-instrument checkpoint/resume qualification, Windows/Linux qualification and
ISSUE-001 (inverse sensitivity to measurement noise) retain their existing limits. ISSUE-001 is an open research question, not a confirmed defect in the current profile.
Reference data must be supplied for the correct ColorChecker variant; InkProf does
not invent reference Lab values or establish ISO conformity from the compact
colour summary. Future profile tweaking remains a proposal, not an implemented
release feature. Historical release tags and assets remain unchanged.
