# InkProf v1.0.0-rc.3 — Dialog and workflow fixes

RC3 is a prerelease following RC2. It includes RC2's profiling, gradient,
FWA/OBA, measurement-revision and certificate updates, plus the fixes below.

## Changes since RC2

- Fix early Save/Cancel/Approve responses in Project details and profile approval
  so those dialogs do not wait again after dismissal.
- Preserve target filenames when a MATLAB character-vector path is imported.
- Add 45-second test-only deadlines and teardown checks to modal dialog tests.
  A timeout is a test failure, never a successful cancellation.
- Update tests for v2 byte-identical ICC import, v4 cancellation, inline HTML
  plots, portable report links and configurable target-paper limits.
- Update all five current documentation PDFs and current version markings to RC3.

## Verification

The full development MATLAB suite completed with 210 passed, 1 failed and 0
incomplete. Its only remaining failure was an obsolete length-policy expectation.
After correcting that test, the entire render-dialog file passed (4/4).
**All 211 unique MATLAB tests have a passing latest result** across the full run
and corrective retest. This is cumulative evidence, not a zero-failure single run.
Four actual Argyll profiles and their gradient diagnostics were included.
Python unittest discovery passed all 172 tests in both development and public
checkouts; source/version/resource and licence-inventory checks also passed.

A temporary-project UI/render/reopen/integrity check passed, and exported workflow
windows were visually inspected. Full manual click-through remains open because
native MATLAB UI access was unreliable. No new physical print or instrument
measurement was performed. Private reference fixtures were used in development;
they are excluded from the public distribution, so this is not complete public
checkout qualification. See VALIDATION.txt and docs/validation/rc2-follow-up.md.

## Upgrade and scope

Use this candidate instead of RC2 for the dialog and target-import fixes. Existing
projects, measurements and original ICCs are preserved. RC2 remains unchanged.
This is not stable v1.0, automatic ISO approval, universal print accuracy or M1
qualification. MATLAB, Python and ArgyllCMS are installed separately.
