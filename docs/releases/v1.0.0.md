# v1.0.0 release preparation

Target: **v1.0.0**. Current marker: **1.0.0-rc.1**, 2026-10-03.

Prepared: current user documentation and reproducible PDF sources; shared version marker in app/source; changelog; source licence headers; dependency/schema/font notice inventory; explicit source-only release scope; automated source-release checker. Actual validation is recorded in ../../VALIDATION.txt.

## Before publishing the stable release

1. Review the recorded validation results and known limitations. Test the normal physical print/measure workflow and the new matte shadow target with the intended hardware; numerical tests alone do not qualify it.
2. If advertising i1Profiler receiver compatibility for the replacement PXF scaffold, repeat that receiver test. InkProf round-trip validation is a separate check.
3. Confirm the desired stable source commit. Change VERSION and resources/release.json together to 1.0.0 / released, update displayed PDF version and rebuild all five PDFs.
4. Run tools/check_release.py, tools/check_license_inventory.py and the applicable Python/MATLAB tests. Verify the public archive contains no local projects, real measurement fixtures or excluded third-party assets. Preserve complete notices and source.
5. Create tag v1.0.0 and publish the public GitHub release with the source archive, five documentation PDFs and validation notes. No stable tag or release is created by this preparation task.

## Known limits

macOS tested; Windows/Linux and every supported instrument/mode are not qualified. The POSIX instrument bridge needs platform work for Windows. ISSUE-001 (inverse sensitivity to measurement noise) remains open. Matte defaults are InkProf choices using documented Argyll options; their physical improvement must be verified. Certificates are documented measurements/decisions, not accredited or complete ISO certification. External runtimes are installed separately.
