# InkProf v1.0.0 — release preparation

Prepared 2026-10-10. Internal version: **1.0.0**. Planned public tag: **v1.0.0**. This preparation creates a GitHub draft, not a published stable release.

## Changes since RC4

- Manual gamut-area selection and measurement reinforcement, clearer blue-sky results.
- Reliable strip progress and retry handling, page RGB print checks before a long measurement, and reasoned overrides with retained evidence.
- Reselect already printed C2 targets for the current ICC and confirm the target before measuring.
- ColorChecker/reference names, paired colour swatches and Delta E00 in certificates.
- Step 8 activity feedback; corrected RGB-reference XYZ handling.
- Portable external delivery with the project-defined profile name and last eight iteration UUID characters. One folder contains ICC, PDF, HTML, supporting evidence and gradient JPG soft proofs through the delivered profile.
- Explicit external-save button, removal of the repeated profile-name prompt and temporary hiding of the app during native file dialogs.
- Swedish/English handbooks with illustrated covers and matching instructions.

## Prepared release assets

Source ZIP with current reviewed public files; five documentation PDFs; VALIDATION.txt; SHA256SUMS. MATLAB, Python and ArgyllCMS are installed separately. The public source excludes private development history, local projects, physical measurement/reference fixtures and runtime binaries.

## Before publication

1. Review the validation record and known limitations against the intended release scope.
2. Review the draft and assets. Any physical or manual workflow qualification beyond the recorded tests remains a human review item.
3. Publish the GitHub draft when the release is approved. Until then no stable release is announced and no stable tag is pushed by this preparation.

## Known limits

macOS tested; Windows/Linux and every supported instrument/mode are not qualified. The POSIX instrument bridge needs platform work for Windows. ISSUE-001 (inverse sensitivity to measurement noise) remains open. Matte defaults are InkProf choices using documented Argyll options; their physical improvement must be verified. Certificates are documented measurements/decisions, not accredited or complete ISO certification. External runtimes are installed separately.

## Rebuild documentation

From the source root, with the report requirements installed:

```sh
python docs/usage/presentation-source/build.py en
python docs/usage/handbook-source/build.py docs/usage/InkProf-anvandarhandbok-svenska.pdf sv

python docs/usage/presentation-source/build.py en docs/usage/InkProf-profiling-workflow-MATLAB-guide-English.pdf docs/usage/workflow-source/en.json
```

PDFs include author/contact, date, page n (total), GitHub link, version marker and embedded font notices. Licence documents themselves remain unmodified.
