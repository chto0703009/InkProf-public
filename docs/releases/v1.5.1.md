# InkProf 1.5.1 - 2026-11-13

- Step 15 is the shared place to add measurement patches. The **Refinement tools** shortcut selects step 15 and opens the same menu.
- **View gamut** opens a rotatable ICC gamut surface for inspection. To create a measurement target, choose **Add patches near the gamut boundary** in step 15.
- InkProf registers each new gamut target for step 16 when it is saved. Use **Resume saved gamut selection** to return to an earlier selection, including a package already printed.
- The Swedish and English handbooks and MATLAB workflow guides describe the updated workflow and include a clickable contents list and PDF bookmarks.
