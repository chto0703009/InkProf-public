# InkProf v1.2.2 — RGB target bug fixes

Released 2026-10-22. Source-only maintenance release.

- Keep the RGB target designer in front while the workflow waits for input.
- Automatically create a separate approximate ICC v2 compatibility copy when an ICC v4 profile is used for target preconditioning. Preserve the original, source hash and numerical conversion evidence. Other import routes retain their confirmation.
- Show activity, calculation phase and elapsed time in the designer during ICC inspection, conversion and target generation.
- Fix TI1/JSON saving: runtime figure references and callbacks are excluded from exported generation settings. This also supports designs already held by a running editor.

## Validation

23 focused MATLAB tests passed (ICC compatibility, activity, RGB design and definition saving). A real cached v4 original produced a v2 copy with its original SHA-256 unchanged. No new full-suite or physical print validation is claimed. See VALIDATION.txt.

## Upgrade

Close InkProf and restart MATLAB after updating. Existing projects and profiles remain unchanged. PDF handbooks/presentations remain at v1.2.1; these patch notes and the target-design Markdown describe the fixes.
