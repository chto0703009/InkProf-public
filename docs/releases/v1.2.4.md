# InkProf v1.2.4 - Verification feedback and complete certificate delivery

Released 2026-10-24. Source-only patch release.

- Distinguish C2a print preparation from C2b measurement, with clearer instructions for remeasuring a new print using the existing ICC.
- Open readable C3 feedback after analysis and reopen it from selected step results.
- Keep row selection as navigation; use explicit approval and certificate actions. A prior numerical-only delivery no longer hides certificate export after current print approval.
- Include a byte-identical `-verified-original.icc` alongside named/converted delivery profiles. Record its path and SHA-256 in the delivery receipt; the certificate remains tied to the checked profile.
- Update bilingual handbooks, technical descriptions and presentations, the English workflow guide and editable Markdown/JSON sources. Refresh version labels on all eight maintained PDFs.

Validation: nine workflow-recommendation regression tests and the separate-delivery integration test, including exact checked-ICC hash assertions. MATLAB source syntax checks, source/version/notice checks, and PDF content/layout/hash verification. No new full-suite or physical printing/instrument qualification is claimed.

Existing project data, measurements, profiles and registered certificates are preserved. Restart InkProf to load updated UI code. MATLAB, Python and ArgyllCMS are separate host dependencies; local runtimes, private projects and real measurement/reference fixtures are excluded.
