# InkProf v1.0.0-rc.4 — ICC versions and updated handbooks

Released 2026-10-09 as a prerelease. [Download v1.0.0-rc.4](https://github.com/chto0703009/InkProf-public/releases/tag/v1.0.0-rc.4).

## Changes since RC3

- Project definition offers **v2**, **v4.4** and **Both** for profile delivery. Existing projects default to v2. Changing delivery format preserves measurement and profiling evidence.
- Optional v4.4 output is derived from the Argyll-built v2 profile, with a conversion report, hashes and unchanged colourimetric tables. Both delivers both versions. A newer version number does not guarantee higher colour accuracy.
- Supported original v4 profiles are read and verified using LittleCMS. Verification retains the original ICC; the separate Argyll compatibility conversion is explicitly described as an approximation.
- Delivery reports distinguish the checked v2 profile from the converted v4.4 variant. Numerical agreement does not establish perceptual-print equivalence or physical print accuracy.
- Updated Swedish and English handbooks explain installation, the complete workflow, status meanings and ICC version selection. Original example screenshots and overview/appendix flowcharts clarify project definition, measurement, profiling and gamut views.
- Corrected handbook cross-references, FWA/smoothing guidance, v4 import wording, dates and Swedish terminology; added a scoped numerical BPC example.
- Corrected PDF spacing, figure cropping, headings and release links. Author/contact information appears only in the footer. The Swedish handbook is named **InkProf-anvandarhandbok-svenska.pdf**. All five maintained PDFs carry RC4.

## Validation and limits

All 214 MATLAB tests passed in a single development run, and all 177 Python tests passed in both development and public checkouts. Source/version/resource and licence-inventory checks passed. See [VALIDATION.txt](../../VALIDATION.txt) for the release checks. Windows/Linux end-to-end operation, a new physical print measurement and complete manual UI qualification remain unverified. Public source excludes private measurement/reference fixtures. MATLAB, Python and ArgyllCMS are installed separately.
