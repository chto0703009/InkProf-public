# InkProf v1.2.5 - Unicode paths and RGB measurement feedback

Released 2026-10-24. Source-only patch release.

- Fix relative-path handling for composed and decomposed Unicode, including åäö ÅÄÖ ü Ü. Apply the shared confined-path helper to project inventories, workflow outputs, target manifests, imports, refinement references, RGB control results and target-package copies.
- Preserve Unicode ICC v2 display names in the Unicode description field, with a readable ASCII fallback for older readers. All other ICC tag payloads remain unchanged.
- Play a short 1200 Hz / 120 ms cue immediately before each manually triggered RGB control measurement, including repeats. Missing audio does not block acquisition. The user confirmed the direct sound test was audible.
- Start the external TIFF-copy chooser in Downloads. Include `C2-verified-profile.icc`, byte-identical to the profile used for the C2 target, with verified hash in print-copy provenance. The TIFF is already transformed: do not apply the companion ICC again when printing.
- Update Markdown usage guides and changelog. The eight PDF guides remain the reviewed v1.2.4 edition; the v1.2.5 Markdown additions describe these new fixes.

Validation: 17 MATLAB Unicode/project/target/copy tests, one C2 ICC-copy regression test and three Python ICC-naming tests passed on the public source. No new full-suite or physical print/instrument qualification is claimed. Existing project artifacts are not rehashed or modified by the release. Previously affected manifests require an audited repair with preserved prior manifests, not silent acceptance of changed files.

Restart MATLAB to load the updated classes and helpers. MATLAB, Python and ArgyllCMS are separate dependencies; local virtual environments, runtime binaries, private projects, measurements and third-party ICC files are excluded.
