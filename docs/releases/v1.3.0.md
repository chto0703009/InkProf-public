# InkProf v1.3.0 - Workflow clarity and measurement reliability

This minor release makes profiling decisions, measurement cancellation and delivery progress clearer while preserving original measurements, profiles and historical reports.

- Correct wrongly recorded project details with a required reason and before/after audit. Descriptive corrections retain valid results when physical conditions are unchanged; numerical processing changes follow normal invalidation.
- Inspect step-4 measurements before entering the assessment. Follow B1, B2 and B3 in the suggested order, with modal B1 confirmation and timed validation/snapshot saving. Initial B3 no longer asks for unused refinement-patch parameters.
- Hear spot-start cues from both screen commands and the i1 Pro 2 physical switch. RGB rows are shorter, page changes are inline and the temporary sound-test control is removed.
- Keep spot acquisition responsive to partial process output and Argyll diagnostic text. Cancel RGB calibration without deleting saved attempt evidence. Clear main-window activity state on interruption.
- See timed certificate/ICC delivery phases; avoid successive automatic C1 windows and close the workflow gamut-selection window after successful saving.
- ISSUE-001 is closed by user decision based on several practical measurements without observed problems. Historical evidence is retained; no full noise-propagation/refitting study is claimed.
- Seven PDF handbooks, technical descriptions, presentations and the MATLAB guide have been updated to 1.3.0. Markdown and editable sources are included. The future-opportunities PDF retains its proposal scope.

## Downloads

Use the source ZIP for installation, or the documentation ZIP for the eight maintained PDF documents and selected Markdown guides. MATLAB, Python and ArgyllCMS are installed separately. Checksums and a source-file manifest are supplied. No private projects, real measurement datasets, ICC profiles or runtime binaries are included.

## Validation and limits

See VALIDATION.txt for the exact automated checks. Synthetic instrument tests cover transport, trigger events, calibration cancellation and preservation; they do not qualify a physical instrument or printer. The changed physical-switch audio path still requires confirmation with the intended instrument. Previous macOS/i1 Pro 2 qualification boundaries remain; Windows/Linux and all instrument modes are not qualified. Independent measured-print verification is still required for colour-quality decisions. Certificates record measurements and assessments; they are not accredited certification.
