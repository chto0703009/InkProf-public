# InkProf v1.4.0 - Measured gamut refinement and balanced profile trials

This minor release adds printable sampling around the current ICC gamut boundary, immutable extension of a saved target, and reviewable density-balanced ICC candidates. Original measurements and the active profile remain preserved.

- Explore either side of the model boundary with valid device RGB; this does not promise expansion of the physical printer gamut.
- Extend the latest completed, unmeasured gamut target into a new complete TIFF16/TI2 package. Skip unprinted proposals, retain selected/shadow points and provenance, exclude duplicate/training RGB, and block extension of targets with started/paused measurements. Print the new package, measure its TI2 in step 16 and build in step 17.
- Review measured Lab density, RGB span and repeated-RGB variability. Adjust provisional thresholds, Recalculate, Select all/Clear all, and build a separate unchanged-row subset candidate. Protected neutrals, extrema and inconsistent repeats remain retained.
- Compare both profiles against ALL original fitting observations (including omitted rows), available reserved development patches and matching photographic gradients. Training diagnostics are not independent print accuracy. Candidates are never selected automatically.
- Rotate the 3D patch review, close View gamut after successful target creation, and default optional external print copies to Downloads after normal project saving.
- Show elapsed time and work stages during density analysis, recalculation and candidate builds.
- Standardize each program's own Python 3.13.6 environment with pinned packages, safe backup/rollback and native architecture preference. Include separately licensed ArgyllCMS 3.5.0 ARM/Intel macOS tools with upstream notices and provenance.
- Update seven PDF guides, editable sources and Markdown for 1.4.0; retain historical documents and the future-development proposal scope.

## Downloads and installation

The source ZIP includes MATLAB/Python source and the two macOS Argyll distributions. Install licensed MATLAB and Python 3.13.6 separately, then run setup_python_environment("sync") from the complete program folder. The documentation ZIP contains seven current PDFs plus the unchanged future-opportunities proposal. SHA256SUMS and the source archive's RELEASE_MANIFEST.json verify the delivered bytes.

Bundled ArgyllCMS keeps its own upstream licences, including AGPL-3.0. Notices, archive provenance, reference files and corresponding-source locations are included. No local .venv, private project, user measurement or user ICC is packaged.

## Validation and limits

See VALIDATION.txt for exact tests and document checks. Synthetic acquisition tests do not qualify physical instruments. Full trial construction was exercised in an isolated project copy with 2,100 original fitting observations; this is a software check, not printer/paper qualification. Density thresholds are experimental. Fresh independent print verification remains required; Windows/Linux and all hardware modes are not qualified by this release.
