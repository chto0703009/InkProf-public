# InkProf v1.1.0 — stable feature release

Released 2026-10-12, authorised by the maintainer. Source version 1.1.0; public tag v1.1.0. [Download the release](https://github.com/chto0703009/InkProf-public/releases/tag/v1.1.0). The minor version reflects the new inner gamut shell refinement feature.

## Main changes

- Sample RGB patches inside an adjustable inner gamut shell, across the whole surface or selected areas. Use geometric ΔE76 thickness, forward RGB evaluation, existing-point exclusion and Lab gap filling.
- Review plotted candidates and shell depth before producing TIFF16. Group shell, image, manual selection, error refinement and higher ICC-grid trials in Refinement tools.
- Register saved print targets without regeneration, preserve measured identities and guide users through steps 15–18.
- Show calculation/copy progress, check RGB controls once per patch on every page, and allow deliberate remeasurement.
- Improve HTML rotation and show actionable C1/Grid reports when a candidate build stops. Preserve the previous active profile.
- Separate complete measurement details and technical evidence into an appendix for both print-verified and numerical-only step 19 certificates. Retain ColorChecker swatches in the main certificate, and label earlier measurements as historical evidence. Match certificate ID and ICC hash and record the appendix checksum.
- Update all five maintained documentation PDFs to 1.1.0.

## Validation scope

Numerical and synthetic checks do not establish physical print quality. MATLAB, Python and ArgyllCMS are installed separately. Historical platform and instrument limits remain applicable. Certificates are not accredited certification. No failed candidate is approved by changing the version.
