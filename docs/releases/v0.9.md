# InkProf v0.9

InkProf - When colours have to be right.

First public source release of the project-based MATLAB profiling workflow.

## Included

- New and existing projects with separate folders and persistent JSON state.
- Ordered operations with prerequisite checks, input hashes and stale-result detection.
- RGB target design/import, saved TIFF16 targets and measurement integration.
- ArgyllCMS ICC candidate generation, numerical checks and measured print verification.
- Traceable iterations, targeted refinement proposals and readable result logs.
- ICC export with PDF/HTML final reports, selected save locations and retained project copies.
- Rotatable 3D view of predicted verification colours, with a still image in reports.
- Swedish and English presentation and MATLAB workflow PDFs.
- GPL-3.0-or-later licence, third-party notices and separately licensed CxF3 schema.

## Installation

See the root README. MATLAB, Python dependencies and ArgyllCMS must be installed separately. The app is started with `startInkProfApp` from the source folder. This release does not include a compiled app or a MATLAB Runtime package.

## Validation and known limits

The public source snapshot is checked with the included Python and MATLAB tests and the recorded licence inventory. Test details are in `VALIDATION.txt` in the release assets.

Development environment: macOS, MATLAB R2025b, Python 3.13, ArgyllCMS 3.5.0. Basic instrument operation has been tried with i1Pro 2. Windows instrument operation and all instrument modes are not qualified. The project app uses Swedish labels; English documentation is included.

Printing and drying take place outside the app. The user makes the final intended-use approval. The 3D plot shows selected predicted control colours, not a complete printer gamut. Internal thresholds and documented ISO references are not ISO certification. Fluorescence compensation and automatic drift approval are not claimed.

## Public-source boundary

The public repository starts from a new history. The original development repository stays private. Third-party target/reference files, vendor screenshots, raw experiment files and dependent tests with unresolved redistribution rights are excluded. The public source contains no runtime binaries or user project folders. See RELEASE_SCOPE.md for details.
