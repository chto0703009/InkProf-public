# InkProf v1.2.1 — local time in the app and readable logs

Released 2026-10-16. Maintenance update to v1.2.0.

## Changes

- Display local time in the close confirmation and iteration-history table/details.
- Use local time in newly appended readable workflow, iteration-progress and feedback logs.
- Convert older certificate UTC timestamps to local display time when a local display field is missing.
- Respect the computer's time zone and the offset applicable to the recorded date, including daylight-saving time and date rollover.
- Preserve UTC machine evidence, existing registered reports, measurements and ICC profiles. Elapsed calculation times remain durations.
- Update documentation and all six documentation PDFs to version 1.2.1.

## Upgrade

Close InkProf and restart MATLAB after updating the source. Existing projects can
be reopened; no new measurement or profile build is required. Newly generated
reports use the revised display. Previously saved files and historical log lines
are not rewritten. The public README and current guides point to v1.2.1.

## Validation and scope

See VALIDATION.txt for exact checks. This patch uses the v1.2.0 full MATLAB suite
as its baseline and reruns focused MATLAB time/workflow/report tests, plus the
full Python suite and public-source checks. It does not claim a new full MATLAB
run or additional physical print/instrument qualification.

Source-only GPL-3.0-or-later release without warranty. MATLAB, Python and ArgyllCMS
are installed separately. Existing platform/instrument limits and the open
ISSUE-001 research question remain. Private project data and restricted fixtures
are excluded. Earlier release tags and assets are unchanged.
