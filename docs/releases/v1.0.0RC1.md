# InkProf v1.0.0RC1

Public release candidate, 2026-10-03. Internal source version: **1.0.0-rc.1**. This is a source distribution for testing before stable v1.0.0, not a standalone application.

InkProf helps photographers and printing businesses connect RGB targets, spectrometer measurements, ICC profiling and documented verification. Open source makes the methods available for inspection, while project JSON preserves settings, evidence and decisions.

## Included

- Persistent projects and guarded profiling/iteration workflows, portable project folders and result logs.
- TIFF16 targets, adjustable paper/sled layouts, spectral measurement and immutable measurement revisions.
- ICC building with ArgyllCMS, numerical checks, physical print verification and iterative refinement from measurements or images.
- External ICC verification with a separate seven-step workflow and balanced photographic targets. The default 575 patches can be changed; selection includes skin tones, shadows, neutrals, broad colours, challenges and repeats. This is an original InkProf target, not a ColorChecker SG reproduction.
- 2D/3D profile comparisons, ICC gamut surfaces and PDF/HTML measurement certificates with evidence, signature area and explanatory/legal appendices.
- Central paper, ink, coating and drying settings; optional optical-brightener processing and matte shadow sampling.
- Swedish/English presentations and workflow PDFs, Swedish handbook and current Markdown usage guides. The Markdown guides cover recent additions beyond the PDF handbook.

## Installation and validation

Install MATLAB, Python and ArgyllCMS separately; follow the repository README. The tag **v1.0.0RC1** identifies this release while VERSION and the app display **1.0.0-rc.1**.

Release recheck: **130 Python tests and 158 MATLAB tests passed**, with no failures or incomplete MATLAB tests. Source/version checks and the recorded licence inventory passed. See **VALIDATION.txt** for the dated full-suite results and manual test scope. Automated tests do not by themselves establish colour accuracy. The user confirmed PXF round8 import/display, printing and measurement in i1Profiler. Balanced verification target generation was additionally checked with a real RGB printer ICC at 140 and 575 patches; those new targets have not been physically qualified by this release test.

## Known limitations

- Tested on macOS with MATLAB R2025b, Python 3.13 and ArgyllCMS 3.5.0. Windows/Linux, all instrument modes and all material combinations are not qualified. The measurement bridge uses POSIX facilities.
- ISSUE-001 (inverse sensitivity to measurement noise) remains open. New matte shadow defaults need physical evaluation with the intended materials.
- External profile training data are unknown; independence from those data cannot be established. Current import support requires a supported RGB printer LUT profile.
- Numerical-only certificates explicitly state when an iteration lacks separate print verification. Certificates are not accredited or complete ISO certification.
- This release preserves GPL and third-party notices; it is not a general legal clearance. The stable-release checklist records unresolved rights questions, including historical vendor-derived PXF assets and bvdm/ISO table reproduction. See docs/releases/v1.0.0.md and licenses/review-v1.0.0.md.

## Distribution

Source only, under GPL-3.0-or-later with separately licensed resources and preserved notices. No private projects, real measurements, third-party ICC profiles or external runtime binaries are added. GitHub provides source ZIP/tar archives; the five current documentation PDFs and validation record are attached separately. Report reproducible problems through GitHub Issues, omitting private data.
