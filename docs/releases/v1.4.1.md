# InkProf 1.4.1

This patch release brings the published package into line with the current code and polished documentation.

## Changes

- Dark refinement sampling reserves approximately one third of its budget for neutral patches and one third for weakly coloured shadows, with the remainder covering other dark colours. Unused quota slots return to the dark pool. New targets use device RGB without ICC conversion; originals are preserved.
- Target-extension documentation now states the actual guard: saved confirmed passes, TI3 readings or measured RGB revisions block extension. Opening a measurement window alone does not.
- Swedish/English handbooks, technical descriptions, workflow guide and version labels are aligned. The runtime description correctly identifies bundled ARM/Intel macOS Argyll tools and the separately prepared Python 3.13.6 environment.
- Internal build diagnostics and workflow row 8 checks are distinguished.

## Validation

The current code passed 59 targeted MATLAB tests and 29 Python tests during the documentation/code audit. Python FWA tests used the bundled native Argyll tools on PATH. These checks use synthetic fixtures and isolated projects; they are not new physical instrument or printer qualification. Seven maintained PDF guides were rebuilt for 1.4.1 and visually checked. Package manifests and SHA-256 checksums are verified before publication.

Existing projects, measured originals, profiles and the v1.4.0 release remain unchanged. The source package includes separately licensed macOS Argyll binaries and upstream notices; private projects and local environments are excluded.

## Swedish workflow guide supplement

The release also includes the reviewed 17-page Swedish workflow guide for 1.4.1, its editable JSON source and PDF builder. Version labels, native-tool terminology and the target-extension guard were corrected. All pages were rendered and visually checked; repository and Downloads copies have matching SHA-256 hashes. The supplemental ZIP supplies these additions without changing the original release tag or archives.
